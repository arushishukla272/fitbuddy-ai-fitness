# FitBuddy - AI Fitness Coach

FitBuddy is a smart AI-based fitness web app that creates personalized diet and workout plans.

### Features
- User Input: Age, Gender, Height, Weight
- AI Logic for BMI, Diet Plan, Workout Plan
- Dashboard to track progress
- Built with Python Flask + SQLite

### How to Run Locally
pip install -r requirements.txt
python app/main.py

### Tech Stack
Python, Flask, HTML, CSS, SQLite
